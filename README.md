A pure-Node program that draws a travel poster for NIMBARA, an invented place where a river climbs out of its valley and up into the dawn sky, with one small red-sailed boat riding the current uphill, and writes it as a PNG to /output/entry.png. No dependencies, no network, fully deterministic.

## Run it

```sh
node main.ts
```
